# Playlist_Maker
 Приложение для поиска песен в базе iTunes и создания плейлистов.
## Используемые технологии и инструменты
- Kotlin
- Rest API
- Room
- Retrofit
- Kotlin Coroutines
- Koin
- ViewBinding
- RecyclerView, DiffUtil
- ViewPager
- SharedPreferences
- Clean Architecture (MVVM)
- Custom View

## Функционал приложения
- Поиск песен в iTunes API
- Прослушивание отрывка песни 30 сек.
- Добавление/удаление треков в избранное
- История поиска
- Создание плейлистов
- Отправить информацию о плейлисте через соцсети 
- Удаление/добавление треков из плейлиста
- Редактирование информации о плейлисте
